03 · Introduction
Background & Context
Setting the stage

Motivation & Context

The Challenge

Engineering students struggle to identify high-yield topics, cognitive complexity levels, and patterns across years of past examination papers. Current approaches rely on informal sharing among peers and anecdotal advice from senior students.

The Opportunity

A single engineering course may have 15–20 years of examination papers — an underutilized resource. With modern AI and ML techniques, meaningful patterns can be extracted from this corpus to transform exam preparation.

04 · Problem Statement
Research Gap
The core challenge

Why Existing Approaches Fall Short

01

No Systematic Topic Analysis

Students lack quantitative data on topic frequency. Cannot prioritize study efforts based on evidence.

02

No Cognitive Complexity Frame

No automated way to determine whether questions test recall, understanding, application, or higher-order analysis skills.

03

No Temporal Weighting

Older papers may contain outdated topics. No mechanism for weighting recent papers more heavily.

04

No Semantic Similarity Detection

Semantically similar questions across different years cannot be identified despite different wording.

Research Question: How can we design an intelligent system that analyzes past questions, identifies topic patterns, classifies cognitive complexity, and provides a conversational study assistant — within a zero-cost architecture?

05 · Objectives & Scope
Aims · Deliverables
Project aims

Objectives & Scope

Primary Objectives

  1. 1Process both native PDFs and scanned PDFs with >85% OCR accuracy
  2. 2Map extracted questions to syllabus topics using LLM-powered semantic analysis
  3. 3Implement weighted frequency analysis with exponential decay for temporal trends
  4. 4Classify questions according to Bloom’s Taxonomy (6 cognitive levels)
  5. 5Provide interactive visualization dashboard with heatmaps, trends, and charts
  6. 6Implement a RAG-powered chat interface for conversational querying

Scope

  • Engineering courses at KNUST, Faculty of Electrical & Computer Engineering
  • PDF documents up to 10MB; courses with ≥3 years of papers
  • Zero-cost deployment (Vercel + Render + Supabase + Groq)
  • Does not provide answer keys or solutions — analysis only

06 · Literature Review
Related Work
Building on existing work

Related Research

Educational Data Mining

EDM & Examination Analysis

Baker & Inventado (2014); Romero & Ventura (2007). Previous work focused on item analysis requiring answer keys. Our system analyzes question content independently of answers.

Cognitive Classification

Bloom’s Taxonomy Automation

Bloom (1956); Anderson & Krathwohl (2001). Singh & Singh (2020) achieved >80% NLP-based classification. Our system integrates Bloom’s with topic extraction and temporal trends.

Large Language Models

LLMs in Educational Analysis

Kasneci et al. (2023). Our system uses Llama 3 via Groq with structured Pydantic output for reliable topic and Bloom’s classification, with retry logic for transient failures.

RAG Systems

Retrieval-Augmented Generation

Lewis et al. (2020); Zhong et al. (2022). Our system stores embedded questions in ChromaDB with cosine similarity threshold >0.85 for semantic search + conversational Q&A.

Research Gap

No existing system combines multi-format ingestion, LLM-powered topic/Bloom’s classification, temporal decay weighting, vector similarity, and a RAG chat assistant in a unified, zero-cost architecture.

This thesis addresses
  • Unified end-to-end analysis pipeline
  • Zero-cost production deployment
  • Integration of all 6 Bloom’s levels with temporal data

09 · Methodology
Weighted Decay Algorithm
Temporal importance scoring

Weighted Decay Algorithm

Mathematical Model

Importance Score = Σ (Frequency × e−λt)

Where: Frequency = occurrences of a topic · t = paper age in years · λ = decay constant (0.3, suggested)

Why This Matters

Recent papers weighted more heavily to account for curriculum changes. A topic from 2024 receives full weight (e0 = 1.0), while one from 2021 receives e−0.9 ≈ 0.41.

11 · Implementation
Dashboard & RAG Chat
User-facing features

Dashboard & RAG Assistant

Analytics Dashboard

  • Topic Frequency Heatmap — Grid showing topic occurrence by year with intensity coloring
  • Trend Line Charts — Topic frequency over time with decay weighting applied
  • Bloom’s Distribution — Pie/bar chart of question complexity levels
  • High-Yield Topics — Ranked list with prediction confidence scores

RAG Study Assistant

  • Semantic search over all embedded questions using ChromaDB
  • Retrieved top-4 relevant questions as context for LLM
  • Conversational responses grounded in specific past questions
  • Example: “How does this course usually test Thevenin’s Theorem?”
Vector Similarity Detection

Each question embedded using sentence-transformers (all-MiniLM-L6-v2) → 384-dimensional vector. Cosine similarity threshold >0.85 identifies semantically similar questions across years, even with different wording.

Responsive Design: Desktop and tablet viewports supported via Tailwind CSS
Real-time: SWR deduplication · 60s analytics caching · Background processing

14 · Discussion
Limitations & Challenges
Honest assessment

Limitations & Challenges

OCR Quality Dependence

Accuracy depends heavily on scan quality. Poor-quality scans with noise, skew, or faded text may fall below the 85% target.

Mitigation: Improved OpenCV preprocessing

LLM API Dependency

System depends on Groq Cloud API availability. Rate limits or service disruptions would impact core analysis functionality.

Mitigation: Local LLM alternatives, response caching

Syllabus Dependency

Topic classification accuracy depends on quality of syllabus topics provided. Poorly defined syllabi receive less accurate classifications.

Mitigation: Structured topic input, LLM fallback

Fixed Decay Constant

Weighted decay uses λ = 0.3 that may not be optimal for all courses. Stable curricula might benefit from lower constants.

Mitigation: Configurable decay parameter

These limitations inform the future work directions outlined in the next slide.
